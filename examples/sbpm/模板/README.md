# 三视图示例的导入与宏

在需要插入内容的 YAML 映射里写 `导入` 列表。列表项可以是相对于当前文件的路径，也可以用 `文件` 和 `参数` 传入实例信息。被导入文件的顶层键加入当前映射。同一模板可以多次导入，只要展开后的键不同。

模板可在键、值或列表元素中使用 `${板卡ID}`。整个值只有一个宏时保留参数原有的 YAML 类型，例如通道列表；嵌入文本时只接受字符串和数字。嵌套导入需显式传参。宏按数据替换，不执行表达式。缺参、多余参数、重复键和循环导入都会报错。

在技能根目录运行：

```sh
python scripts/ontology.py expand examples/sbpm/双板模板复用.yaml
python scripts/ontology.py expand examples/sbpm/束测机箱-数据.yaml
```

输出是展开后的 UTF-8 YAML，可交给后续的引用检查或可视化程序。导入宏使用 `${名称}`；数据视图原有的 `{前缀}:{通道}:WF` 仍留给 PV 映射阶段。物理视图的“参考文档”和“模板”仍是普通引用。
